#### Menu Additional Options
### 1. Add Options in "Kelola Menu & Kategori" page
## 1.1 Drinks
-In "Kelola Kategori" Add an option to add a "Drinks" tag for creating new categories or old categories, if a category has that tag, automaticly add Cupsize, Sugar, Ice/Hot options to items that belongs in a category that has a "Drinks" tag
-Cupsize is Large, Medium, Small.
-Sugar is Less or More Sugar
-Ice or Hot option
-For Ice, has Less or More Ice
-The Cupsize, Sugar, Ice/Hot options is called "additionals"
-These additionals will appear in Kasir, Receipts, Open Bill Receipts
# 1.1.1 Drinks UX Flow
-[1] User open menu
-[2] User clicks "Kelola Kategori"
-[3] User sees next to "Hapus" button, new button "Add tag"
-[4] User clicks "Add tag"
-[5] User sees "Drinks"
-[6] If User clicks "Drinks", then the category has a "Drinks" tag added to it
-[7] User will see items that belongs in a category that has a "Drinks" tag, has "additonals" that'll show below items in Kasir when User opens "Keranjang"
